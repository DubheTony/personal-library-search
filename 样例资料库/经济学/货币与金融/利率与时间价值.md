# 利率与时间价值

利率表示一定时期内资金使用权的价格，通常用本金的一定比例表示。借款人支付利息，换取提前使用资金；储蓄者则放弃当前消费，以获得之后的本息。利率因而连接不同时间的收入与支出，但它不只是“多出多少钱”，还反映期限、风险和资金供求等条件。

简单利息按原始本金计算，复利则把已产生的利息并入之后的计息基础。若年利率为 r、计息 n 期、起始本金为 P，在利率固定且每期复利的简化假设下，期末金额可写为 P(1+r)^n。真实存款、贷款可能按不同周期计息，也会受费用、税费和利率调整影响，不能把公式不加条件地套用到所有产品。

时间价值来自资源用途的差异。现在可用的资金可以用于消费、储蓄或投资；未来收到的同额资金则要等待，还可能受到购买力变化和不确定性的影响。因此比较两个时间点的金额时，要说明采用的贴现率与期限。贴现是把未来金额换算为当前等价价值的一种方法，结果随假设改变。

名义利率没有扣除物价变化，实际利率则试图描述购买力层面的收益。若物价上涨，账面金额增加并不一定代表能购买更多。日常近似讨论中，实际利率可理解为名义利率减去通胀率；更精确的计算需考虑复利关系。选择储蓄或贷款时，也要看费用、流动性、期限匹配和风险。

不同利率之间不能只比数字大小。长期贷款利率通常反映更长的承诺期限，浮动利率会随基准条件变化，固定利率则把部分未来不确定性转移给合同双方。比较方案前，应把计息方式、付款日期和总费用统一到同一口径。

利率是金融分析的重要变量，但不会独自决定家庭或企业的行为。未来收入是否稳定、项目能否产生回报、借款能否按时偿还，也同样重要。将利率视为一项假设来分析，而不是保证收益的承诺，能减少对单一百分比的误读。

不同计息频率会改变名义年利率相同条件下的实际增长速度，比较产品时要把期限与复利周期统一。贷款还可能包含手续费、提前还款条件和浮动条款，单独看利率无法代表全部成本。利率分析的价值在于把未来现金流放到同一时间尺度上，而不是用公式替代对合同条件和风险的检查。
