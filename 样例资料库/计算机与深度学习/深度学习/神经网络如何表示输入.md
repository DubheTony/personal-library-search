# 神经网络如何表示输入

神经网络会先把图片、声音等输入转换成按约定组织的数值。灰度图可以表示成像素矩阵，彩色图每个位置包含多个通道，文字需要先转换成词元编号或向量，声音则能切成连续片段并计算特征。输入的形状和含义必须与模型训练时保持一致，否则模型即使成功运行，也可能把数据解释错。

向量、矩阵和更高维数组统称张量。一个张量由数据值、形状和数据类型共同构成。形状说明每个维度有多少元素，例如一批大小为 b、每个样本有 d 个特征的数据，可表示为 b 行、d 列的矩阵。批次维度让模型一次处理多个样本；若训练和预测时维度顺序不一致，矩阵运算就会失败，或把样本和特征混在一起。

网络中的一层通常把输入映射成新的表示。线性层把输入向量与权重矩阵相乘，再加入偏置；非线性函数让多层组合能够表示更复杂的关系。每一层的输出是模型在训练中形成的内部编码，隐藏层通常没有唯一的自然语言解释。判断模型是否工作，要结合整体任务表现和有针对性的分析，不能把某一个神经元直接对应到特定概念。

输入预处理决定数据怎样进入张量。图像常需要统一大小和像素尺度，文本需要按模型规定切分，数值特征可能需要归一化。训练和使用时必须执行一致的处理流程；同一变量若训练时按一种单位缩放，预测时又按另一种方式转换，模型看到的数值分布就会改变。

数据类型也影响计算结果。浮点精度越高，通常表示范围和精细程度越好，但计算和存储成本也更大。较低精度可以加速部分模型运算，却需要确认关键步骤仍稳定。形状、设备位置和精度设置应作为输入管线的一部分检查，而不是等模型给出奇怪答案后才回头猜测。

建立输入表示时，先说明每个维度代表什么，再写转换步骤，并用少量已知样本检查转换后的形状和数值范围。这样的检查能把数据错误与模型错误分开，也让模型训练过程更容易复现。

标签也需要用明确的表示方式传入模型。分类任务可将类别编码成整数，再通过嵌入层映射为向量；多标签任务则可能为每个类别保留独立标记。编码规则一旦变化，模型所学的含义也随之变化。文件格式、缺失值和异常范围同样属于输入契约，应在数据进入网络前统一处理。
