# 调制与解调

无线通信需要把信息变成适合通过信道传输的信号。调制把信息映射到载波的某种特征上，常见做法是改变载波的幅度、频率或相位。载波本身可以是规律的高频振荡，调制后它的变化跟随待传信息，接收端再通过解调恢复相应内容。

幅度调制让载波幅度随信息变化，结构直观，但容易受到幅度噪声影响。频率调制主要让瞬时频率随信息改变，在某些噪声条件下更稳健，不过通常需要一定带宽。相位调制改变载波相位，数字通信还可以用多个相位或幅度状态表示符号。不同调制方式在抗干扰、带宽和实现复杂度上各有取舍。

调制前的信息要经过编码和成形。数字比特不能直接被天线发送为抽象的 0 和 1，而要映射成可传输的波形。符号率描述每秒传输多少个符号，比特率则描述每秒传输多少比特；一个符号若可表示多个比特，两者就不相同。脉冲成形可以限制频谱扩展，减少相邻信道互相影响。

信道会引入噪声、衰减和多径效应。接收信号与载波同步不准时，解调结果可能产生误差；幅度变化也可能同时来自信息和传播过程。接收机通常需要滤波、放大、频率变换、同步和判决等步骤，具体顺序取决于调制方式和系统结构。

数字调制中的星座图把不同符号表示为平面上的点，横纵坐标通常对应同相与正交分量。噪声会使接收点偏离理想位置，判决器需要判断它最接近哪个符号。点距越小，同等噪声下越容易误判；增加状态数可以提高频谱利用率，但也可能提高对信噪比和同步精度的要求。

调制与解调应成对设计。发送端的符号映射、带宽限制和载波参数必须与接收端的解调假设一致。测试系统时，可以分别检查基带、已调波和恢复信号，确认误差来自编码、信道还是同步环节，避免只凭最终声音判断全部链路。

接收端还需估计载波频率和相位。若本振偏差较大，星座点会旋转或扩散，判决错误随之增加；同步环路可以持续跟踪偏差，但响应过快也可能追随噪声。调制方式必须结合信道条件与接收机能力选择，不能只凭理论频谱效率判断系统整体更好。
